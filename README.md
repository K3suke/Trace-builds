# Trace: test builds

Trace is a stylized tactical FPS in development. This repository only holds downloadable test builds for friends and testers.

## Install (Windows 10/11, 64-bit)

1. Open **[Releases](../../releases/latest)** and download **`Trace-<version>-Setup.exe`**.
2. Run it and answer **Yes** to "Install Trace?". Nothing needs admin rights; the game goes in your user folder, with a Start menu and desktop shortcut.
3. Windows may say "Windows protected your PC": the test build isn't code-signed. Click **More info → Run anyway**.

Prefer no installer? Download **`Trace-<version>-win64.zip`**, unzip it anywhere, and run `Trace.exe`.

**Uninstall:** Windows Settings → Apps → Trace → Uninstall. Your settings are kept in `%APPDATA%\Godot\app_userdata\Trace`.

## Playing together online

- **Steam must be running** on every PC (you'll show as playing "Spacewar" on Steam while the game uses a test ID).
- Main menu → **Multiplayer → Team deathmatch**. Pick your team (USA or Russia).
- One player clicks **Host on Steam** and either invites friends (**Invite friends** opens the Steam overlay) or lets them use **Find matches**.
- The host picks **Versus** (players on both sides, bots fill to 6v6) or **Co-op** (everyone against bots), Day or Night, and presses **Start match**.
- On the same home network you can also use **Host** / **Join** by address instead of Steam.

## Single player

**Clear the house** (a timed mission) or **Free range** (endless fight), on Old Town Crossing by day or by night.
